GET 청크 영상 조회

지정된 시간의 청크 영상을 조회하고 재생합니다.

ISO 시간 형식(예: 2026-02-06T10:18:34.19)을 입력 후 "변환" 버튼을 누르면 Unix 나노초로 변환됩니다.

GET 롤업 정보

현재 시간 버튼을 클릭하면 Start Time은 현재 시간, End Time은 5초 후로 자동 설정됩니다.

GET 데이터 Gap 분석

지정된 간격으로 데이터를 조회하여 빠진 시간대를 분석합니다.

카메라 설정 파일에서 테이블 이름을 자동으로 가져옵니다.

데이터 조회 간격 (기본값: 5초)

예: 2024-01-01T10:00:00Z

현재 시간 버튼: Start = 현재, End = 5초 후 (RFC3339 형식)
